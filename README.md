# Heart Disease Prediction: Exploratory Data Analysis & Predictive Modeling

## 1. Project Overview

This project explores the key factors associated with heart disease and develops a predictive model using Python and Machine Learning techniques.

Using a dataset containing approximately 100,000 patient records, the project investigates relationships between demographic characteristics, lifestyle behaviors, health indicators, and heart disease.

In addition to exploratory analysis and predictive modeling, an interactive desktop application was developed using Tkinter to provide accessible insights into heart health.

**Project Type:** Data Analytics & Machine Learning

**Dataset Size:** 100,000 patient records

**Main Model:** Logistic Regression

**Programming Language:** Python

## 2. Project Objectives

- Explore demographic and lifestyle factors associated with heart disease.
- Investigate relationships between variables such as age, smoking status, and physical activity.
- Perform Exploratory Data Analysis (EDA) to identify meaningful patterns and trends.
- Develop a Logistic Regression model for heart disease prediction.
- Build an interactive application to communicate analytical insights.

## 3. Dataset

**Dataset:** Heart Disease Prediction Dataset 2026

**Source:** [Heart Disease Prediction Dataset 2026 – GitHub](https://github.com/mohan13krishna/Heart-Disease-Prediction-Dataset-2026)

The dataset contains approximately 100,000 patient records with demographic, lifestyle, and health-related variables.

The analysis focuses on factors including:

- Age
- Smoking status
- Physical activity
- BMI
- Blood pressure
- Sleep duration
- Stress level
- Heart disease status

## 5. Project Workflow

### Phase 1: Data Exploration & Preparation
- Load and inspect the dataset.
- Examine data types and missing values.
- Explore data distributions and descriptive statistics.
- Prepare data for further analysis.

### Phase 2: Exploratory Data Analysis (EDA)
- Analyze demographic characteristics.
- Investigate lifestyle factors associated with heart disease.
- Explore relationships between health indicators and heart disease.
- Visualize patterns using charts and statistical plots.

### Phase 3: Statistical Analysis
- Examine associations between selected variables and heart disease.
- Investigate the relationship between lifestyle behaviors and heart health.
- Interpret statistical findings.

### Phase 4: Predictive Modeling
- Develop a Logistic Regression model.
- Prepare training and testing datasets.
- Evaluate model performance.
- Explore predicted heart disease probabilities.

### Phase 5: Interactive Application
Develop a desktop application using Tkinter.

The application allows users to:
- Enter selected personal health indicators.
- Select smoking status and physical activity level.
- Explore heart disease percentages across relevant categories.
- View simplified analytical insights.

## 6. Key Findings

The analysis explores several potential relationships between heart disease and demographic, lifestyle, and health-related factors.

Key areas of investigation include:

- Age-related differences in heart disease prevalence.
- Differences across smoking status categories.
- Associations between physical activity and heart disease.
- The contribution of health indicators to predictive modeling.

## 8. How to Run the Project

### Prerequisites

- Python 3.10 or later
- Jupyter Notebook or Visual Studio Code

### Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn statsmodels
```

### Run the Jupyter Notebook

Open `Python_Bootcamp_Project.ipynb` in Jupyter Notebook or VSCode and execute the cells.

### Run the Tkinter Application

```bash
python heart_health_tkinter.py
```

## 9. Limitations

- The analysis is based on the available dataset and its recorded variables.
- Observed associations do not necessarily imply causal relationships.
- Model predictions are statistical estimates and should not be interpreted as medical diagnoses.
- The application is designed for educational and analytical purposes, not clinical decision-making.
